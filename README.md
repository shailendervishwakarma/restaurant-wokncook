# 🍜 WOK'n'COOK - Restaurant Web Application

Welcome to **WOK'n'COOK**, a fully responsive web application for an Asian cuisine restaurant. This project features an interactive dynamic menu, bill calculation, order management form, customer feedback system, and a backend PHP handler for processing submissions[cite: 1, 2, 4].

---

## 🚀 Features

* **Interactive Dynamic Menu**: Features 100+ delicious dishes spanning across Indian, Chinese, Continental, and other cuisines with category sorting and dynamic quantity controls.
* **Live Bill Calculator**: Select items, customize quantities, and instantly compute total bills before checking out[cite: 2, 4].
* **Order & Delivery Management**: Supports Dine-In, Takeaway, and Home Delivery options with conditional address validation[cite: 2, 4].
* **Backend Processing**: Seamlessly handles order confirmations and customer feedback submissions via `backend.php`[cite: 1, 4].
* **Responsive Styling**: Custom CSS (`king.css`) with smooth scroll zooms, grid layouts, and modern UI elements.
